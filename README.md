# טפסי נסיעה לחו"ל

אתר שממלא שני טפסים קבועים (התחייבות אשראי לפני נסיעה, התחשבנות אחרי נסיעה) לפי תשובות המשתמש.
הכל רץ בדפדפן – אין שרת ואין שמירה של פרטי בנק/אשראי.

## הרצה מקומית
```bash
python3 -m http.server 8765
```
ואז לפתוח http://localhost:8765 (צריך שרת – פתיחה ישירה של index.html לא תטען את קובצי ה-PDF).

## אירוח
אפשר להעלות את התיקייה כמו שהיא לכל אירוח סטטי (GitHub Pages, Netlify, Cloudflare Pages).
הקבצים הנדרשים: `index.html`, `style.css`, `app.js`, `fill.js`, `lib/`, `fonts/`, `forms/`.

## מבנה
- `fill.js` – מיקומי השדות בכל טופס (בנקודות PDF) והלוגיקה שכותבת טקסט עברי מימין לשמאל.
- `app.js` – השאלון, משטח החתימה וההורדה.
- `forms/` – הטפסים המקוריים.
- `tools/` – כלי פיתוח: `test-fill.js` ממלא את שני הטפסים בנתוני דוגמה (`node tools/test-fill.js <תיקייה>`).
